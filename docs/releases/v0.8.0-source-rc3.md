# 0.8.0-source-rc3 — candidato de revisión

Fecha: 2026-11-13.

RC3 corrige la recuperación tras un fallo de instalación cuando ya existía una copia
base de esa versión. El rollback utiliza ahora una copia del estado inmediatamente
anterior a la operación. La desinstalación conserva su copia histórica independiente.

Se añade un bloqueo común de instalación/desinstalación, rechazo de diarios pendientes
de otros candidatos y recuperación explícita antes de permitir una nueva instalación.
El payload incluye las licencias completas MIT y BSD de pyserial 3.5 y sus avisos.
El constructor incorpora la identidad normalizada y la URL preview del plugin.

Se mantiene RC2 en el canal preview hasta validar RC3. El firmware, el protocolo
serie y el control térmico no se modifican. No se declara una versión estable.

## Validación

Construcción determinista, auditoría estructural y simulaciones de arranque; nuevas
regresiones de instalación fallida, interrupción, reintento, bloqueo y licencias.
Los resultados completos de Python 3.11/3.12 y PHP figuran en Actions del commit.

La instalación y el ciclo de vida de RC3 en Unraid siguen pendientes de prueba.
Consultar [el plan de validación](../VALIDATION-RC3.md). La actualización manual
requiere el daemon detenido y ENABLE ausente; no inicia el servicio automáticamente.
